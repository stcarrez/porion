porion add: add a new project or a new recipe

  The porion add command is used to add a new project or a new recipe
  to an existing project.

Usage: porion add {<git|tar>}

  Create a new project with the source scheme.
  A default project name is created from the source scheme name
  and a set of build recipes are guessed by analysing the sources.

Usage: porion add --recipe {<ident>} [<source-ident>]

  Add a new recipe with the given identification and initialize
  it from either the main project recipe or from the given source
  identification recipe.  The recipe identification string is composed of:

  <project-name>[#<branch-name>][~<recipe-name>][@<node-name]

  You may also specify a build number with the pattern:

  <project-name>:<build-number>

Examples:
  porion add https://gitlab.com/stcarrez/ada-util.git
  porion add git@github.com:stcarrez/ada-util.git
  porion add --recipe ada-util~release
  porion add --recipe ada-util~release ada-util:25
