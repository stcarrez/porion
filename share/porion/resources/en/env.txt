porion env: set or unset build environment variables

Usage: porion env
       porion env <ident> [NAME=VALUE]...
       porion env @<node> [NAME=VALUE]...

  Without argument, list all the environment variables that are defined.

  Configure the environment variables used to build a project, a branch,
  a specific recipe or on a build node.  The environment variables are
  associated with `ident` which is composed of:

  <project-name>[#<branch-name>][~<recipe-name>][@<node-name>]

  The environment variables of a build node are selected with the
  @<node-name> form.  Each remaining argument must have the NAME=VALUE
  form and defines or replaces the value of the variable.

Examples:
  porion env
  porion env ada-util MAKEFLAGS=-j4
  porion env ada-util#master~release COVERAGE=yes
  porion env @local CFLAGS="-O2 -g"
