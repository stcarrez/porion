porion info: report some information about a project, a recipe or a build

Usage: porion info [--all] [--recipes] [--nodes] [--builds] ident...

  For each project, report a short description of the project and its branches.
  If the project has been built, report the last build of the project.

  The --nodes option activates the report to list the build nodes where the
  project is built.

  The --recipes option provides a list of the recipes to build the project.

  The --builds option gives the list of builds of the project.

  The --all option activates all the reports.

Examples:
  porion info ada-util
  porion info --all ada-util
  porion info --recipes --builds ada-util
  porion info ada-util:25
