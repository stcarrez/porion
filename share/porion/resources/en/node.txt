porion node: add, update or remove build nodes

Usage: porion node {uri}

  Add a build node described by the URI.  The build node can be a remote
  server access through an SSH connection, a docker container, a virtual
  machine that is controlled through virsh.

  local://hostname/directory
  ssh://[login@]hostname[:port]/directory
  docker:image
  virsh:image

Usage: porion node {-u|--update} {uri} [directory]

  With the --update option, update the build node configuration with
  the given name.

Usage: porion node {-r|--remove} {name}

  With the --remove option, remove the build node that have the given name.
  The 'local' node cannot be removed.

Usage: porion node {-P|--probe} {name}

  With the --probe option, probe the status of the build node to verify its
  status and get some system information about it.

Examples:
  porion node ssh://builder@build.example.com/var/porion
  porion node docker:porion-builder
  porion node --update ssh://builder@build.example.com/var/porion /var/porion
  porion node --probe local
  porion node --remove builder
