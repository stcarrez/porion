porion step: control the recipe build steps

  The `porion step` command is used to add, update or remove a recipe
  build step.  After updating the recipe, the list of build steps is
  printed unless the `--quiet` option is passed.

  The recipe is identified by the identification string composed of:

  <project-name>[#<branch-name>][~<recipe-name>][@<node-name]

Usage: porion step [--quiet] [--ignore-error] [--disable] [--timeout <N>]
                   [--insert <POS>] <ident> command [args...]

  Add a new build step to a project build recipe.

  By default the new step is appended to the build recipe and the
  `--insert <POS>` option allows to insert it at some specific position.

  The `--ignore-error` option configures the build step to ignore error
  if the command execution failed and the `--disable` option disables
  the build step and it will be not executed.

  The `--timeout <N>` option configures the maximum time allowed for
  the execution of the command.

Usage: porion step --update <POS> [--quiet] [--ignore-error] [--timeout <N>]
                   [--disable] <ident> [command args...]

  Update the timeout, the execution mode or the command for the given build
  recipe step.

Usage: porion step --remove <POS> <ident>

  Remove the build step at the given position in the build recipe.
